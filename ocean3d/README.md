# 딥 블루 3D : 바다 청소부 — 빌드 소스

`../ocean-cleanup-3d.html` 은 이 폴더의 소스를 번들링한 **단일 HTML 파일**입니다 (Three.js 포함, 외부 리소스 없음, 오프라인 동작). 브라우저에서 파일을 바로 열면 됩니다.

## 빌드
```bash
cd ocean3d
npm install
npm run build   # → ../ocean-cleanup-3d.html
```

## 테스트
```bash
cd ocean3d
npm install
npx playwright install chromium   # 처음 한 번
npm run build && npm test          # 전체 (core·sites·story·quality·touch)
npm test -- story touch            # 일부만
```
`tests/e2e.mjs`는 빌드된 `../ocean-cleanup-3d.html`을 헤드리스 Chromium(소프트웨어 GPU)으로 열어 수거·빔·소나·도킹·업그레이드·구조·도감·지도·수압 실패·저장/이어하기, 하얀 산호 지대 정화, 스토리 모드 끝까지 진행과 퀴즈, 그래픽 품질 자동 조절과 WebGL 컨텍스트 복구, 태블릿 터치 버튼 배치와 터치 조작(조이스틱 데드존·옆 이동, 피치 보정, 빔 조준 범위, 첫 플레이 힌트)을 확인합니다. GitHub에서는 `main`에 push할 때마다 `.github/workflows/game-tests.yml`이 빌드 결과가 커밋된 파일과 같은지와 이 테스트를 함께 돌립니다.

## 그래픽 품질
설정의 기본값은 **자동**입니다. 플레이 중 실제 프레임 시간을 재서, 4초 동안 약 40fps 아래면 한 단계 내리고(다시 올리지 않음), 6초 동안 55fps 이상이면 한 번 **최고**(픽셀 밀도 2배, 외부 카메라 화면 매 프레임 갱신)로 올립니다. 휴대폰(터치 화면, 짧은 변 600px 미만)은 한 단계 낮은 **보통**에서 시작해 **높음**까지만 오르고, 조종석 외부 카메라 화면은 높음부터 켜집니다. 메모리를 4GB 이하로 알리는 기기(Chrome)도 한 단계 낮게 시작합니다. Safari가 메모리 부족으로 WebGL 컨텍스트를 회수하면 저장·일시정지 후 안내를 띄우고, 복구되면 그대로 이어집니다.

## 터치 조작
- 왼쪽 조이스틱: 앞뒤·좌우로 이동합니다(옆으로 밀면 옆으로 미끄러지듯 이동하고 시점은 돌지 않음). 방향 전환은 오른쪽 화면 드래그로만 합니다. 12% 데드존과 완만한 감도 곡선이 있어 엄지가 조금 흔들려도 움직이지 않습니다.
- 오른쪽 화면을 끌지 않은 채 1.2초 넘게 전진하면, 26°보다 가파른 위·아래 시선이 서서히 그 각도로 돌아옵니다. 빔을 쓰는 중에는 조준을 건드리지 않습니다.
- 터치에서는 빔이 조준선에서 약 9° 더 벗어난 쓰레기·그물·밸브까지 잡습니다.
- 첫 플레이에서는 두 드래그 영역에 손가락 힌트가 뜨고 각각 한 번 써 보면 사라집니다. 앞에 쓰레기가 있으면 빔 버튼이 「꾹 누르기」로 깜박이다가, 빔으로 한 번 수거하면 멈춥니다(저장됨).
- 수거·충돌 때 진동합니다. iOS/iPadOS Safari는 진동 API를 지원하지 않아 Android에서만 느껴집니다.

## 모바일 전체 화면
- 터치 기기에서 게임을 시작하면(새 게임·이어하기·스토리) `requestFullscreen`으로 전체 화면을 요청하고, Android에서는 가로로 고정합니다. HUD 오른쪽 위 ⛶ 버튼으로 전환합니다. 지원하지 않는 브라우저에서는 버튼이 숨겨집니다.
- iPhone의 브라우저는 모두 사파리 엔진이라 페이지 전체 화면이 안 되므로, 제목 화면에 안내가 나옵니다(사파리: 「툴바 가리기」와 「홈 화면에 추가」, 크롬·파이어폭스·엣지: 「홈 화면에 추가」). 루트의 `manifest.webmanifest`(전체 화면·가로)와 `apple-touch-icon.png`·`icon-192.png`·`icon-512.png`, `apple-mobile-web-app-capable` 메타 태그로 홈 화면에서 주소창 없이 열립니다. 시작 URL은 추가한 페이지 그대로라 스토리 링크에서 추가하면 스토리 모드로 열립니다.
- 노치·다이내믹 아일랜드: `#safe` 요소로 safe-area inset을 읽어 HUD와 터치 버튼을 그 안쪽에 두고, 제목·대화 상자·모달도 inset만큼 띄웁니다.
