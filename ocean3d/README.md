# 딥 블루 3D : 바다 청소부 — 빌드 소스

`../ocean-cleanup-3d.html` 은 이 폴더의 소스를 번들링한 **단일 HTML 파일**입니다 (Three.js 포함, 외부 리소스 없음, 오프라인 동작). 브라우저에서 파일을 바로 열면 됩니다.

## 구조
| 파일 | 내용 |
| --- | --- |
| `src/main.js` | 렌더러·블룸, 플레이어/카메라, 생물 AI, 아이템·소나·빔·구조, 열수구 검은 연기·착륙선 신호등, 정화 현장(난파선·비행기 잔해 진행도·기름 유출·정화 후 돌아오는 물고기, 하얀 산호 지대의 밸브 잠그기와 산호 색 회복), 임무·도감·지도·세이브, UI/입력, 메인 루프 |
| `src/world.js` | 절차 생성 해저 지형(대륙붕 언덕·사구 → 협곡이 파인 사면 → 능선과 해산이 있는 심해평원 → 해구), 코스틱 셰이더, 수면·하늘, 켈프·산호 7종 군락(겹치지 않게 배치)·불가사리·성게·심해 발광 산호·암석, 두 동강 난 화물선 난파선·부서진 쌍발 여객기(평탄한 해저 바닥 위, 정화 현장 좌표 제공), 혹등고래 골격과 뼈먹는벌레·박테리아 매트의 고래 낙하, 컨테이너선, 광물 굴뚝·관벌레·홍합·흰 게의 열수구, 해구 바닥의 연구용 착륙선·유리해면·바다나리·바다돼지, 기지선. `buildBleach`: 기지선 북쪽 하얀 산호 지대(백화 산호, 폐수 배출관과 밸브) |
| `src/models.js` | 잠수정, 쓰레기 21종(화물 상자·구명조끼·기체 파편·항공기 좌석·여행 가방 포함), 해양생물 17종과 배경 물고기 9종 로우폴리 모델 |
| `src/cockpit.js` | 1인칭 조종석: 화면 전체 유리창(캐노피 프레임·반사) 정적 아트, 유리 위에 뜨는 반투명 계기(레이더·소나 프로파일·계기·경고등)와 입력에 따라 움직이는 조이스틱 캔버스(외부 카메라 화면은 `main.js`가 WebGL 캔버스 모서리에 먼저 그려 복사) |
| `src/audio.js` | WebAudio 절차 사운드(환경음·모터·빔·효과음·생성형 음악). 탭이 숨겨지면 멈추고, 돌아오거나 다음 입력이 있으면 다시 재생 |
| `src/data.js` | 쓰레기/생물/업그레이드/장소 데이터 |
| `src/index.html` | HUD·모달 UI 템플릿 (`/*__BUNDLE__*/` 자리에 번들 삽입) |

## 빌드
```bash
cd ocean3d
npm install
npm run build   # → ../ocean-cleanup-3d.html
```
