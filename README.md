# 딥 블루 3D (SDG 프로젝트)

잠수정을 타고 바다 쓰레기를 수거하는 3D 해양 탐험 게임입니다. Three.js로 만든 단일 HTML 파일이라 브라우저에서 바로 실행됩니다.

- **플레이:** https://bhtwork.github.io/deep-blue-3d/ (GitHub Pages)
- **스토리 모드 (수업용, 약 5분):** https://bhtwork.github.io/deep-blue-3d/story.html — 초등학생 대상 SDG 14 수업용. 돌고래 푸른이의 안내로 쓰레기 줍기 → 바다거북 구하기 → 하얀 산호 지대 살리기 → 주운 쓰레기를 배로 가져가 재활용하기를 하고, 마지막에 실천 약속과 OX 퀴즈 3문제가 나옵니다. 저장하지 않으며 실패하지 않습니다.

- **휴대폰·태블릿에서 전체 화면:**
  - Android·iPad: 새 게임, 이어하기, 스토리 모드를 누르면 자동으로 전체 화면이 됩니다(오른쪽 위 ⛶ 버튼으로 켜고 끔).
  - iPhone: 애플 정책상 아이폰의 모든 브라우저(크롬 포함, 내부 엔진이 사파리와 같음)는 웹페이지 전체 화면을 지원하지 않습니다. 대신 제목 화면에서 **화면을 위로 쓸어 올리면** 주소창·탭 막대가 접혀 전체 화면처럼 됩니다(안내가 나옵니다). 그래도 안 되면 사파리 주소창 왼쪽 「가가」 버튼 → 「툴바 가리기」, 앱처럼 완전한 전체 화면은 공유 버튼 → 「홈 화면에 추가」 후 그 아이콘으로 열면 됩니다(스토리 링크에서 추가하면 스토리 모드로 열림). 제목 화면에도 이 안내가 나옵니다. 홈 화면 앱은 사파리와 저장 공간이 따로라서 진행 상황이 이어지지 않습니다.
- **로컬 실행:** `ocean-cleanup-3d.html`을 브라우저로 열면 됩니다.
- **소스와 빌드:** [`ocean3d/`](ocean3d/README.md) — `cd ocean3d && npm install && node build.mjs`로 `ocean-cleanup-3d.html`을 다시 만듭니다.
