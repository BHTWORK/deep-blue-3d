# 딥 블루 3D (SDG 프로젝트)

잠수정을 타고 바다 쓰레기를 수거하는 3D 해양 탐험 게임입니다. Three.js로 만든 단일 HTML 파일이라 브라우저에서 바로 실행됩니다.

- **플레이:** https://bhtwork.github.io/deep-blue-3d/ (GitHub Pages)
- **스토리 모드 (수업용, 약 5분):** https://bhtwork.github.io/deep-blue-3d/story.html — 초등학생 대상 SDG 14 수업용. 돌고래 푸른이의 안내로 쓰레기 줍기 → 바다거북 구하기 → 하얀 산호 지대 살리기를 하고, 마지막에 실천 약속과 OX 퀴즈 3문제가 나옵니다. 저장하지 않으며 실패하지 않습니다.
